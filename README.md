# PowerShell

Skriptsammlung für die Windows-Administration der DLRG-Jugend Andernach: Updates, Richtlinien, Personalisierung, Inventur und Monitoring. Ein Watchdog kopiert die Skripte bei jeder Anmeldung aus einer Sync-Quelle und führt sie aus.

## Quickstart

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\Ausführung\WatchDogInstall.ps1
```

Als normaler Benutzer ausführen. Skripte mit Systemzugriff vorher in einer Testumgebung prüfen.
